# Listing placeholder images — AI-generated, not photographs

Every `.jpg` in this folder was **generated by an image model**. None of them is
a photograph, and none of them shows a real car that exists or is for sale.

They exist so the site can be demoed with plausible-looking listings while the
real inventory is still being collected. They are named by listing slug
(`toyota-corolla-2015-xli.jpg`) and are used only as a fallback:
`lib/strapi.js` prefers the listing's Strapi `gallery`, and falls back here when
that gallery is empty.

## Replace these before launch

NICHE.md makes "the price you see is the real price" and verified listings the
whole proposition. A generated picture of a car that does not exist is exactly
the kind of thing the business exists to oppose, so:

- **Never let these reach real buyers.** They are pre-launch scaffolding only.
- Upload real seller photos to the listing's `gallery` in Strapi
  (Content Manager → Listing → Gallery). The moment a gallery has one image,
  that listing stops using this folder — no code change needed.
- `toCar()` exposes `hasPlaceholderImage: true` while a listing is still on a
  placeholder, so a pre-launch check can assert that none remain.
